1. 특강 안내

아이의 읽기가 멈추는 지점부터
다시 연결합니다.

새로운 규칙을 빠르게 훑기보다, 이미 배운 소리를 실제 단어와 문장에 적용하는 과정을 충분히 반복합니다.

이런 아이에게 추천해요

“알고는 있는데, 읽지는 못해요.”

  • 글자 소리를 각각 말하지만 단어로 붙이지 못하는 아이
  • 연습한 단어는 읽지만 처음 보는 단어에서 멈추는 아이
  • 그림이나 첫 글자만 보고 단어를 추측하는 아이
  • 단어는 읽어도 문장에서는 자주 끊기고 지치는 아이
90

시간 가는 줄 모르는 수업

다양한 상호작용과 재미있는 활동을 촘촘하게 연결해, 아이가 자연스럽게 몰입하는 90분 수업으로 운영합니다.

7–10

지루할 틈 없는 전환

듣기, 말하기, 글자 타일, 신체 활동, 읽기 게임이 7~10분 단위로 자연스럽게 이어집니다.

1:6

최대 6명 소그룹

아동의 오류 방식과 도움 반응을 가까이에서 관찰하고, 같은 활동 안에서도 난도와 힌트를 개인별로 조절합니다.

8회 학습 흐름

수업 순서는 기초 기획안을 유지하면서 ‘규칙 이해’보다 ‘실제 읽기 적용’을 강화합니다.

1회

읽기 상태 확인

배운 파닉스가 어디에서 읽기로 연결되지 않는지 편안한 게임으로 살펴봅니다.

2–3회

자음 소리 자동화

자음 소리를 빠르게 떠올리고 첫소리·끝소리를 단어 읽기에 적용합니다.

4–5회

단모음과 CVC 읽기

짧은 모음을 구별하고 세 소리를 끊지 않고 붙여 단어와 문장으로 읽습니다.

6회

이중자음 연결

sh, ch, th, wh 등의 소리를 단어와 생활 문장 속에서 읽습니다.

7회

장모음과 생활영어

대표 장모음 규칙을 여행·쇼핑 상황의 단어와 표현으로 연결합니다.

8회

읽기 성장 확인

누적 게임, 나만의 영어 카드 발표, 사전·사후 읽기 변화를 확인합니다.
