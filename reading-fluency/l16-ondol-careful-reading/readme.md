# 방바닥을 데우는 온돌

부주의한 아동을 위한 초등 사회·과학 연계 주의깊게 읽기 수업입니다. 같은 7단계 흐름 안에서 `차근차근 읽기(70)`와 `깊이 읽기(82)` 본문 및 문항이 함께 전환됩니다.

## 실행

`session01.html`을 로컬 웹 서버에서 엽니다.

- 차근차근 읽기: `session01.html?level=steady`
- 깊이 읽기: `session01.html?level=deep`
- 난이도 선택 화면: `session01.html`

## 수업 초점

- 아궁이, 방고래, 구들장, 두둑, 굴뚝의 역할을 구분합니다.
- 뜨거운 공기와 연기가 움직이는 순서를 확인합니다.
- 단어스파이는 학생과 젤리코치가 번갈아 칸을 표시합니다.
- 학생이 틀린 칸은 코치에게 넘어가지 않고 중립으로 남습니다.
