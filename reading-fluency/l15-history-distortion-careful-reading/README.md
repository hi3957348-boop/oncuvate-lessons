# 같은 역사, 왜 다르게 말할까?

부주의한 아동을 위한 초등 사회·역사 꼼꼼 읽기 수업입니다. 같은 7단계 흐름 안에서 `차근차근 읽기(75)`와 `깊이 읽기(85)` 본문 및 문항이 함께 전환됩니다.

## 실행

`session01.html`을 로컬 웹 서버에서 엽니다.

- 차근차근 읽기: `session01.html?level=steady`
- 깊이 읽기: `session01.html?level=deep`
- 난이도 선택 화면: `session01.html`

## 수업 초점

- 사실을 바꾸지 않은 설명의 차이와 역사 왜곡을 구분합니다.
- 중요한 사실 빼기, 실제보다 크게 말하기, 없던 일 더하기를 구별합니다.
- 설명을 만든 사람과 사용한 자료를 확인하고 서로 다른 기록을 비교합니다.
- 삽화는 거친 색연필 스타일의 독립 자산으로 분리되어 있습니다.
