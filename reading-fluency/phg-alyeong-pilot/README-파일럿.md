# 파일럿 사본 — 플랫폼에 올리지 마세요

`release/pilot-realtime-bridge.js`가 실시간 통로를 직접 엽니다.
그래서 **규격 6장(실시간은 플랫폼이 주입)에 어긋납니다.** 일부러 그렇습니다.

## 여는 법 — 주소 하나

    index.html

코치는 「방 만들기」(코치 암호 필요), 학생은 그 숫자를 넣고 「들어가기」.

**방은 먼저 연 사람이 코치**가 됩니다. 같은 코치 링크를 뒤늦게 열면 학생으로 들어갑니다.
**코치가 「페이지 잠금」을 켜야** 학생 화면이 따라옵니다.

## 젤리캡쳐

- 칸을 누르면 낱말이 그 자리에 뜨고 소리가 납니다. 다시 누르면 닫힙니다.
- **이지모드**를 켜면 젤리를 잘못 놓았을 때 어긴 규칙을 그 자리에서 알려 줍니다.
  (정답은 알려 주지 않습니다.)

파일럿이 끝나면 이 폴더는 지웁니다.
