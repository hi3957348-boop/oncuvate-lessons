# 일기예보 꼼꼼 읽기 — 온큐베이트 파일럿

- 콘텐츠 ID: `l10-forecast-careful-reading`
- 시작 파일: `session01.html`
- 실시간 연동: `nav` · `prog`
- 정식 플랫폼 주입값: `window.ONCUVATE`

코치 화면은 우측 상단의 접이식 패널에서 학생의 현재 단계, 최근 답, 도움 요청, 완료 상태를 확인할 수 있습니다. 코치는 전체 화면 이동과 이동 잠금을 제어합니다.

수업방이 없거나 플랫폼 브리지가 주입되지 않은 환경에서는 외부 전송 없이 기존 혼자하기 모드로 동작합니다. 별도 Firebase 초기화, API 키, 자체 입장 코드는 포함하지 않습니다.
