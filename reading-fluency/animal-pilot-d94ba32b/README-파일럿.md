# 파일럿 사본 — 플랫폼에 올리지 마세요

`release/pilot-realtime-bridge.js`가 실시간 통로를 직접 엽니다.
그래서 **규격 6장(실시간은 플랫폼이 주입)에 어긋납니다.** 일부러 그렇습니다.

폴더 이름 뒤의 임의 문자는 **주소를 못 맞히게** 하려는 것입니다. 인증이 아닙니다 —
주소를 아는 사람은 볼 수 있습니다.

## 여는 법 — 주소 하나

    index.html

코치는 「방 만들기」(코치 암호 필요), 학생은 그 숫자를 넣고 「들어가기」.
**방은 먼저 연 사람이 코치**가 됩니다. **코치가 「페이지 잠금」을 켜야** 학생이 따라옵니다.

## 젤리캡쳐

- 칸을 누르면 낱말이 그 자리에 뜨고 소리가 납니다. 다시 누르면 닫힙니다.
- **이지모드**: 젤리를 잘못 놓으면 어긴 규칙을 알려 줍니다(정답은 알려 주지 않음).
- **확정 표시**: 색마다 옳게 하나 놓으면 그 색이 조용해지고 젤리에 체크가 붙습니다.

수업이 끝나면 `pilot-publish.py animal --off` 로 내립니다.
